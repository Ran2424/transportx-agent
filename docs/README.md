## 维护规则

现行规则写入架构或操作文档；待实施的工作保留一份计划。完成的计划、阶段流水和被替代的审查材料不继续作为有效入口，历史内容通过 Git 查询，例如 `git log -- docs/`。已发布版本记录、验收证据和仍被使用的产品媒体保留。

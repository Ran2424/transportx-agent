# ADR 0002 · 运行恢复与 Host 访问

2026-11-14 · 已采纳

## RPC 交付

会话记录有持久 ID，每次启动生成新的 Live Session ID。Host 以持久会话和客户端命令 ID 去重、记录 Live Session 代次。同一代次重试复用回执，迟到回执只能结清同代记录。待处理及交付未知的命令占用活跃额度。作业、进程和生命周期关闭均确认后，旧代记录移出活跃额度，各 Host 最多保存最近 200 条拒绝重放记录，最长 10 分钟。终止未确认时保留活跃记录。

账本跟随 Host 进程。Host 重启后原 Live Session ID 已失效。页面存活期间，Browser Kernel 将待处理或回执未知的命令绑定到首次发往的 Live Session，发现代次变化后提示查看历史。同一 ID 在 Host 重启或拒绝记录过期后，由客户端主动改绑到新代次时没有持久去重保证。若产品需要跨重启补发，需先定义与 Pi 执行副作用共同提交的回执或应用级幂等键。

## 仿真提交

浏览器 GET 读取现有 Run 记录和已发布回放数据。实验 GET 返回当前比较状态；该状态已有冻结清单和报告时返回对应引用。已有工具 POST 负责创建冻结比较和恢复执行。执行恢复在工作区运行门禁内复核会话、工具 token、绑定和写租约。仅在进程退出及成果完整性得到确认后提交完成记录；提交之后释放匹配的工作区占用。恢复对相同未知原因保留原记录，对已结束的运行只清理残留占用。占用属于其他 Run 时返回冲突，进程退出未确认或证据不足时保留占用。

现有磁盘结构和工具版本可继续使用。回滚 Host 会恢复旧实现中 GET 触发的恢复和比较写入。运行没有足够证据时，工作区进程恢复与明确取消仍是人工处置入口。若后续希望在 Host 启动时自动恢复，先确定租约交接、诊断可见性与恢复失败重试预算。

## HTTP 与部署

Origin 依据连接协议及 Host 头计算，只有显式配置的 TCP 对端可覆盖协议。可信代理需启用远程访问和认证，并隔离 Agent Host 监听端口。代理配置错误会影响浏览器连接或认证 Cookie，部署前以外部 URL 核验 HTTP、WebSocket 和认证。桌面及 CLI 的私有回环 Host 独立于代理配置。转发链、跨域白名单及多信任域需要单独设计。

认证配置提交点是设置落盘。写入失败保留现有 HTTP 和 WebSocket 授权状态。响应开始后出现异常时关闭流连接，诊断保留 HTTP 方法、路径和故障码。认证启用时匿名健康响应提供探针字段，认证后的请求可读取其余诊断信息。

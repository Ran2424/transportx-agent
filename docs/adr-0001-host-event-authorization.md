# ADR 0001 · 工作站 Host 的认证与事件投递

2026-11-14 · 已采纳

TransportX 是单用户工作站应用。显式启用远程访问时，多个客户端可以访问同一信任域。Pi 和可信 Module 以该工作站的执行身份运行。工作区与工具 token 约束资源与工具入口。引入互不信任的用户时需重新评估身份、事件归属、文件、原生进程和模型凭据隔离。

HTTP 与 WebSocket 复用同一认证判定。WebSocket 握手、初始状态和后续广播都检查授权。内置 Cookie 带有明确到期时间，连接设置到期检查，并在每次投递前重新判定，以覆盖定时器延迟。凭据变更会使原 Cookie 或 Basic 凭据失效。启用认证后 Host 立即复核已有连接。认证失败时先清理订阅和计时器，再发关闭帧。已经排入网络缓冲区的字节无法撤回。

Basic 使用握手凭据，无单独的连接有效期。新的 Cookie 经客户端重连生效。项目认证适配器目前提供同步查询，消息投递时复核，空闲连接每 20 秒复核一次。外部撤销以适配器能观察到的状态为准。如果产品接入带推送撤销或显式有效期的身份提供方，再扩展该边界。连接心跳负责检测存活。

该决定沿用现有 Cookie、WebSocket 协议及客户端重连流程。回滚相关代码无需迁移，但会重新暴露过期连接的事件投递缺口。

## 3.23.2 - 未发布

### Fixed

- 删除已隔离迁移源前核验目录归属、嵌套/重叠工作区与 Native 历史边界，并在跨 Host 删除租约内重新检查，防止递归删除其他已登记工作区；无法证明归属的目录继续保留。
- 工作区迁移不再凭 Pi 历史的 cwd 自动导入软件工作区根目录之外的项目；先前误收录来源保留审计记录并退出活动清单，原文件和 catalog 删除保护保留。软件内主动创建的自定义目录工作区不受影响。
- Linux 工作区占用检查只把已确认 cwd 位于目标目录内的同用户进程视为遗留成员；cwd 不可确认的无关进程不再阻塞所有迁移、删除与移动操作。应用自身的 Pi/Python 进程仍由运行时记录核验。
- 大量旧工作区启动时，迁移路径冲突检查分批让出主线程；工作区列表复用单次清单读取，避免逐项重复解析全量清单导致桌面健康检查超时和界面长时间等待。
- 激活前核验目标冻结计划和已知模型，校验失败保留当前实例；关闭或删除可取消校验、信任与握手中的启动，迟到结果不再派生 Pi。恢复时核对磁盘 Module ID/精确版本，移除退役模块的自动替换与跳过。
- 空会话不再用 header、恢复或文件修改时间伪造对话活动；未知时间单独标识，无消息时仅用创建时间排序。共享附件显示上传会话，界面区分创建冻结、旧工作区计划和用户确认当前配置的来源。
- 修复健康状态刷新导致相同消息 Markdown 重建、引用详情关闭后键盘焦点丢失；历史图片保留替代文字。全局索引阻塞时仍允许认证和日志诊断，迁移页可直接打开日志目录。

- 核对 Pi 0.80.10 全部 RPC 事件、消息增量与九种 Extension UI 方法：补齐 `session_info_changed` 的会话名称同步；只有四种问答请求进入待回答队列，通知不再回传回答，`set_editor_text` 更新会话草稿，终端呈现提示显式忽略，不再弹出不支持对话框。CLI 不再因单向 UI 通知或重试前的 `agent_end` 中止任务，以 `agent_settled` 为完成边界；覆盖检查随 Pi 事件类型与 UI 方法定义更新。
- 修复发送引导或 Pi 后续消息入队、出队时，将 `queue_update` 通知误报为未知 RPC 事件的问题；实际消息仍由消息生命周期事件写入对话，保留其他未知事件的协议诊断。
- 内置模块在恢复会话时从当前应用根目录解析代码入口，不继续绑定旧开发 worktree；安装模块路径、Native Runtime 哈希与数据资产检查仍保持。CAD 导入与源路径打开复用同一图纸身份，源变化时提示提交候选，避免重复视图。
- 修复 CAD 文字/图块旋转和图块缩放未生效、多份复制重叠、外部参照漏报及预览实际尺寸与回执不符的问题。

- 修复模型 length 终止没有正文时静默结束：输出上限与上下文不足分别提示并记录，历史恢复保留错误；继续入口准备核对成果的续写草稿，不重放已完成修改。模型配置分别保存上下文窗口与最大输出，保留显式 1M 配置及重新保存后的额度。
- CAD 1.3.0 将选区明确为参考信息，移除编辑范围限制，保留版本/哈希、文件边界与持久执行保护；回执返回完整续改信息，支持同轮 r1→r2→r3。顶部工具栏提供点选、框选、平移、附加上下文、刷新图纸和适合窗口，刷新重新读取并校验文件。
- 修复 CAD 查询只向模型返回摘要、完整哈希和实体隐藏在 details 的问题；Tool Activation 1.0.1 的命名查询返回完整嵌套 Schema，启用后返回工具摘要并沿 Pi 下一轮开放定义，Host 补模块描述。Canvas 1.4.1 明确上下文不限制编辑范围；Module Authoring 1.2.2 避免截断检查结果 JSON。回归断言并入既有 40 个测试；仅开发环境验收。

- CAD 1.2.0 改为官方可选 Capability，Workbench 1.4.1 移除默认 CAD 依赖；沿用统一 Tool Contract、Host Client、bundle 与按需启用。Canvas 1.4.0 支持用户和 Agent 打开同一 DXF，首次打开保存原始 r1 快照，重新打开复用图纸；Canvas 呈现操作不改变 CAD 内容版本。
- CAD 选区固定当前轮上下文、revision 与 DXF 哈希；查询和编辑可直接引用 contextId，Host 解析并核验基础版本。选区作为意图参考，允许任务所需的实体修改与新增标注；拒绝旧版本与外部篡改。提交以 manifest 为准，保留按调用 ID 查询、取消与中断恢复，未知结果不自动重绘。
- CAD 按契约、文件与提交、几何操作、投影、检查和渲染拆分；前端功能移入 features/cad，SDK 加载串行且按会话/版本/哈希隔离，修订后保留视野与图层显示。普通修改不自动导出或重复完整检查，已有图纸可按需导出 PNG/PDF 而不创建修订。通用检查与交通规则分开，Skill 参考按需读取，字体根据运行时实际资源解析；OS 入口继续复用平台 profile。
- CAD 转换显式声明 sourceCrs 与目标坐标变换，明确图纸轴向平移、道路偏移和 GIS 重算的差异。Viewer 保持白纸，控制区使用三主题 semantic token，功能文字不少于 11px。本轮仅进行开发环境验收；Windows 与安装包验收后置。

- 修复 Tool Activation 打包规则遗漏：排除与 bundle 映射目标重复的原始 Extension 入口，沿用其他核心模块的交付路径；现有桌面运行时场景统一核对全部核心模块的入口排除规则。本轮不构建或发行安装包。

- 开发启动 `desktop:dev` 与 `start.sh` 支持项目本地 `.env.local` 的 Python 覆盖配置，保留导出变量优先及安装包内置运行时；会话规则统一使用 Host 注入的解释器探测依赖，避免将系统 Python 的缺库误报为整机缺失。运筹优化本地模块提供 1.0.1 修订包，移除裸 `python3` 与 `pip3` 指引，保留旧安装版本。

- 修复桌面 Spatial Python 入口仍指向 asar 虚拟路径的问题，复用现有 unpacked 路径解析后再启动外部 Python；两试点 bundle 的 FileSet 按构建源路径声明解包，保证物理入口存在。

- Spatial Analysis Module 升级至 1.2.0：贯穿 Pi 调用 ID、取消信号和超时，区分确认拒绝/失败、取消与结果未知；错误经 Pi 错误通道写入历史。工作台显示结果未知，且本轮含未确认分析时不提供整轮准备重试。语义拒绝不创建输出目录，确认失败清理本次目录；manifest 原子写入，提交或进程停止无法确认时保留成果，不自动重算。可选引用呈现异常保留已确认分析。
- 修复 Module 目录安装预先创建复制目标导致 Windows `fs.cpSync(errorOnExist)` 报 `EEXIST`；目标目录由复制操作创建，保留拒绝覆盖已有版本的规则。
- Pi 0.80.10 依赖增加固定版本的资源发现补丁：TransportX 关闭全部自动资源后跳过 npm/git 包发现，阻止启动/reload 的隐式包管理器执行；安装和 server 构建自动应用，Pi 升级或源码不匹配时拒绝构建。保留 Pi Registry、Agent Loop、RPC 和显式 Extension，不引入第二套 Runtime。
- Citation Module 升级至 2.0.2：工具说明明确本地文件 `sources` 与网页 `webUrls` 须分次登记、另一字段须省略，网址不能填入文件 `path`；混传时报错给出重试方法及两次 Evidence ID 的复用方式，避免将参数冲突误判为网页引用服务不可用。
- Citation 2.0 注册表升级归入工作区迁移，取得 Writer 与目标维护租约后备份、核验并转换到 3.0；保留历史消息、引用 ID、来源哈希与定位。日常激活只读新结构，不再补做旧格式转换。损坏原件留在目标诊断中，不影响其他 ready 工作区。
- 修复交付成果标题误入 32px 图标列导致的竖排和卡片过高；恢复文件图标与打开入口，放大图标并缩小内边距与卡片间距，长标题最多两行并保留完整标题提示，次要信息显示文件格式、类型与大小。Web 冒烟覆盖多项长标题、窄会话栏和三主题布局。
- Document Canvas 的 update 操作保证 revision 递增，文档与 Office 视图随 revision 自动重载，PDF 同步重建预览；文件修改时间相同或回退时仍可更新，focus 保留导航语义（#69）。
- 引用读取区分原件变化、视图哈希不匹配、文件缺失、越权及内部读取失败；原件不可读时仍展示已登记的版本元信息。原件变化后可经现有授权入口打开任务目录内的当前文件，明确标注非引用版本，并停用失效原件的下载操作；不替换历史引用、不保存历史文件副本（#67）。

### Added

- 工作区与会话改用持久 workspaceId/conversationId、catalog 和工作区 Manifest。保存后无需输入或 Pi 文件即可列出；浏览历史与显式激活分离，同目录会话冻结独立计划，默认配置只影响后续新会话。管理版本与默认版本独立，已有工作区创建同时校验两者；请求在版本校验前去重。
- 生产 Host 接入全局清点与逐工作区迁移。仅备份实际改写元数据，保留 Native JSONL 原件、来源摘要与阶段报告；歧义关联经核验绑定或明确隔离。提供报告、修复后重试、重新准备及整项源隔离入口；索引/墓碑不可信时停止全局业务，局部异常不阻断其他 ready 工作区及新建任务。
- Pi 激活、转换和删除共用工作区排他门禁；跨 Host 按路径真实身份协调，运行记录保存进程代次。忙碌切换需明确停止，停止及最终提交未确认时保留占用；恢复只允许重新核验或停止已证实归属的进程。附件原件、业务文件和引用由工作区共享；附件消息引用、Canvas/Geo 上下文及计时按会话隔离。
- 会话与整个工作区分别删除，按 invocation、历史、私有状态/目录分阶段提交，并保留墓碑、固定身份与可续跑错误。删除会话保留共享资料与其他历史；删除整个工作区需独立确认。
- 公开工作区/会话和资源接口统一到新协议，移除旧创建、路径恢复、历史删除与通用资源消费者。桌面、Web、CLI 使用协议 2；HTTP 写入版本头与 WebSocket 握手在业务前校验，健康检查区分地址可用、初始化、数据阻塞与就绪。侧栏按工作区分组，标签、草稿和 Kernel 使用持久会话身份，重新激活时替换实际 live ID，并拒绝旧实例迟到事件。
- 新资源定位复核当前会话计划、资产哈希及发布证明；普通文件/Canvas 不开放平台私有元数据，无法核验的跨会话高级引用返回不可用。旧本机普通文件地址经当前会话目录与真实路径核验后，投影到新文件/图片地址；归属未知、其他工作区及私有元数据保持不可用，不改写 Native 历史或复用旧鉴权查询参数。
- 本轮为集成分支开发验收，未迁移用户数据，未构建新安装包、发布或合入 main。实施证据与平台验收范围见 [P0 记录](<工作区与会话机制整改 P0 记录.md>)。

- 新增 [工作台视觉优化 PLAN](<工作台视觉优化 PLAN.md>)：保留 Light / Dark / Sand 三套正式主题及现有工作台结构，明确表面层级、组件尺度、卡片与列表职责、P0–P4 实施顺序和三主题验收矩阵；补充 Canvas 之外的面板、导航、详情展开、浮层及输入区过渡，包含候选节奏、中断、减少动态效果与录屏验收。本次仅落档，未修改 UI 或默认主题行为。
- 输入框上方展示 Pi 等待处理的引导与后续消息；`queue_update` 同步独立会话队列，消费后自动移除，保留重复消息。Host 在会话列表与 Snapshot 中返回去除内部上下文后的队列，支持会话切换、页面刷新和断线重连恢复，沿用 revision 防止旧 Snapshot 复活已消费消息；不混入浏览器本地待发送队列或自动重发。
- CAD 1.4.0 定位为通用二维协作工作空间：Python/其他引擎候选可通过 `commit-candidate` 持续提交同一 fileId 的修订，与原生编辑共用版本/哈希、执行恢复和 Canvas；回执说明呈现接受状态与旧引用需重新查询。Skill 以通用创作阶段指导协作，交通规则保持按需参考。

- Web Bridge 1.3.0 增加仅重载模型配置的工作台命令，刷新与切换模型前同步当前空闲会话；带确认的控制请求不产生对话或模型调用，忙碌/旧会话显示原因，不重启工具模块。

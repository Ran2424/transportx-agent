## 用户问题与范围

已安装客户端没有应用内新版发现与安装流程，需要用户自行寻找安装包。本版本自动检查 stable 更新，显示版本和说明，由用户决定下载及重启安装；任务忙碌时保持当前版本。

范围为软件更新计划 P0–P4 的主程序、Host 协调、UI 与发布链路。独立 Module 更新 P5、强制更新、多通道、热替换及自动回滚不在本版本范围。

## 兼容性与发布前置条件

不改变用户数据格式，不改内置 Module 内容及版本，不引入数据迁移。旧会话精确 Module 恢复仍须验收，不能仅凭用户目录独立认定兼容。

用户确认尚未准备正式签名条件与 Windows 构建主机，本轮完成代码和可执行的本地验收。本机无有效代码签名身份；Windows 正式构建和升级需要 Windows x64 主机。当前不能证明正式在线更新可用，不发布线上清单。package / PLATFORM_VERSION 在发布准备时统一提升至目标版本。

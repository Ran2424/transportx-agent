## 用户问题与范围

已安装客户端没有应用内新版发现与安装流程，需要用户自行寻找安装包。本版本自动检查 stable 更新，显示版本和说明，由用户决定下载及重启安装；任务忙碌时保持当前版本。

范围为软件更新计划 P0–P4 的主程序、Host 协调、UI 与发布链路。独立 Module 更新 P5、强制更新、多通道、热替换及自动回滚不在本版本范围。

本版本同时纳入系统架构整改，以及 #44 测试环境依赖、#46 会话草稿保存、#47 地图截图渲染等待、#48 已上传文件清单与复用的修复。完整用户可见变更见 [CHANGELOG](../CHANGELOG.md#3230---2026-10-11)，架构及 Issue 验收见 [执行计划](../架构整改执行计划.md) 与 [问题记录](../Issue解决情况与待办问题.md)。

## 兼容性与发布前置条件

用户确认尚未准备正式签名条件与 Windows 构建主机，本轮完成代码和可执行的本地验收。本机无 Developer ID 代码签名身份；Windows 正式构建和升级需要 Windows x64 主机。正式签名在线升级仍未验收；2026-10-15 经用户明确授权发布 Mac ad-hoc 内测包并开放 Mac 更新清单，记录见下文。2026-10-11 已同步 package、锁文件根版本及 PLATFORM_VERSION 至 3.23.0；版本准备本身不表示安装包已发布。

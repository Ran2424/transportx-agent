## Windows x64

用户于 Mac 发布期间补充要求发布 `TransportX-Agent-3.24.0-win-x64-setup.exe`。已复制原文件并验证字节一致，NSIS 容器、内置应用 3.24.0 / x64、官方 OSS 更新地址均符合文件声明；安装器无 Authenticode 证书。

包内 runtime manifest 记录源码 `26bf9a338f85133175f2061bc6fb0cc7c6947648`、`source.dirty=true`，依赖锁哈希为 `b4b3987939ee24a6996bb90a7759e0f1909f6b9c1a9fb39e256c60e578f4354f`。比对 884 个 Mac 主程序文件后有 80 个不同或缺失项（含打包资产名称）；`bin/api-routes.js` 确有 Mac main 没有的城市轨道交通空间活力 Demo 路由。因此不能把该 Windows 包记为 Mac 同源 main 构建。

用户在获知上述差异后明确选择“按提供的 Windows 包原样发布，注明来源差异”。本次发布按该授权使用原安装包，不把 `source.dirty` 改写为 false，不声称与 Mac 同源，也不填造 Windows 运行验收。

- [EXE](https://download.transkgllm.com/releases/v3.24.0/TransportX-Agent-3.24.0-win-x64-setup.exe) 为 271,779,120 bytes（259.2 MiB），SHA-256 `cb8a907883ce662dd58478a340de4e7710bc69ca708f86af36d8e67b528c20fb`。
- 使用 electron-builder 的 blockmap 实现生成外置 gzip blockmap，未修改 EXE 字节；包内应用为 PE32+ x86-64，安装器 PE 证书目录为空。未在 Mac 上构建或运行 Windows 应用。
- OSS 版本目录与 Windows 更新目录均上传 EXE、blockmap；版本目录另含 SHA-256、安装说明、Windows 发布说明和 [构建信息](https://download.transkgllm.com/releases/v3.24.0/build-info-win-3.24.0.json)。所有对象通过公开 HTTPS HEAD/Range、大小与哈希元数据检查后，最后写入 [Windows 更新清单](https://download.transkgllm.com/updates/stable/win-x64/latest.yml)，使用 `Cache-Control: no-cache`。
- [Windows Actions 镜像](https://github.com/Ran2424/transportx-agent/actions/runs/40687915388) 按用户确认的源码状态及固定 SHA-256 校验后追加 EXE；GitHub 上 8 个 Windows 文件逐一核对大小和服务端 SHA-256。安装器未使用 Authenticode 签名，Windows 安装和升级运行验收仍未执行。
- [官网 PR #20](https://github.com/transportx-public/website-resource/pull/20) 已合并，[部署 40688057311](https://github.com/transportx-public/website-resource/actions/runs/40688057311) 成功，更新中英文 Windows 版本、259.2 MiB 大小与下载及校验链接，保留 Mac 3.24.0 元数据。

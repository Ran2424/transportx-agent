# 交通仿真 P3：上海 OSM 技术测试

2026-11-11，分支 `codex/traffic-simulation-p3-osm`，基于 P2 提交 `51d1e44`。**上海约 3 km 技术测试通过；P3 的真实运营校准未完成。** [证据摘要](acceptance/traffic-simulation-p3-osm-shanghai.json)

用户指定上海，选取上海南站—龙漕路附近的道路和 3 号线轨道。3 km 指试验车辆行驶里程，不是裁剪框宽度或完整公交换乘出行的长度。起终点是测试锚点；车辆参数、停站、客流、班次及接续规则均为合成输入。

## 导入与物理运行

从 [OSM Map API](https://api.openstreetmap.org/api/0.6/map?bbox=121.422,31.150,121.450,31.179) 获取 WGS84 原始快照（22,348 节点、3,277 ways，SHA-256 `ebf7f2233dcf974af0bcb063816528c15424e705213e3167732bc08f1e3821aa`）。© [OpenStreetMap contributors，ODbL](https://www.openstreetmap.org/copyright)。快照及派生路网保存在本地 `tmp/`，不随代码发布。

使用 Traffic Simulation 0.3.0 独立包内 SUMO 1.28.0 的 [netconvert OSM 入口](https://sumo.dlr.de/docs/Networks/Import/OpenStreetMap.html)，直接输入原始 XML，保留所列道路类型及 subway，生成 UTM 51N 路网（645 条普通边、其中 89 条允许 subway；1,360,026 字节）。无手工改写拓扑。轨道边回查至原始 3 号线 OSM 关系 `6817178`。道路起止边位于柳州路与龙吴路附近，公交、小汽车都通过车类可达性检查。

同一次物理 SUMO 运行的实际输出：

| 方式 | 到达 / 计划 | 实际单车里程 | 核验证据 |
|---|---:|---:|---|
| 公交 | 1/1 | 3.216 km | 527 s 到达，指定车道停站 8 s |
| 3 号线地铁 | 1/1 | 3.130 km | 188 s 行程，指定轨道停站 8 s |
| 小汽车 | 12/12 | 3.216 km | 最后一辆在仿真 1041 s 到达 |

里程取实际 tripinfo，含路口内部连接；只累计普通边到停车点分别是道路 2.984 km、地铁 3.038 km。根据实际路线的内部连接独立复核里程，并检查每辆车的轨迹、有效到达、停车记录。1,500 s 测试窗口内无碰撞、无传送。以同一 OSM 快照、转换条件、种子复跑，解析后路网、车辆记录、停站及采样数量一致；原始文件哈希仍分别记录。

试跑捕获两个问题：SUMO 要求车辆按出发时刻写入，否则忽略乱序车辆；900 s 会截断四辆汽车。验收脚本已排序，并将独立物理探针窗口设为 1,500 s；TransportX 的 600 s 上限未改。转换日志保留 OSM 停站关系不全、部分限制关系方向未识别等告警；通过的是选中路径的技术运行，未完成信号、转向、站台和其他道路的现场核验。

## 复现与下一阶段依赖

使用上面哈希匹配的本地 OSM 快照（实时 API 后续可能返回不同版本）。已有 0.3.0 独立包及编译后的 Host 时运行以下命令，两个输出目录应尚不存在。Python 使用项目要求的 3.10 解释器并显式设置 `TAU_PYTHON_COMMAND`。

```sh
MODULE="$PWD/desktop/build/traffic-simulation/com.transportx.traffic-simulation/0.3.0"
PYTHONPATH="$MODULE/runtimes/sumo/python" "$TAU_PYTHON_COMMAND" \
  scripts/simulation/osm-corridor-probe.py \
  tmp/simulation-p3-osm-input/shanghai-south.osm.xml "$MODULE" tmp/p3-shanghai-physical
node scripts/simulation/osm-corridor-host-probe.mjs \
  tmp/p3-shanghai-physical "$MODULE" tmp/p3-shanghai-host
```

实际运行保留在 `tmp/simulation-p3-shanghai-verified`、`tmp/simulation-p3-shanghai-repeat`、`tmp/simulation-p3-shanghai-host-first`、`tmp/simulation-p3-shanghai-host-complete`。新探针未注册 Node 测试；预算仍为 40/40。P3 退出仍需真实客流、队列、发车、载客与运行时长以及独立日期验证和误差门槛；不以该测试推断上海或虹桥运营收益，也不跳过 P4。

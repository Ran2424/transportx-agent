# 文档归档

`docs/` 根目录仅保留当前权威文档：

- [ARCHITECTURE.md](../ARCHITECTURE.md)：系统架构、边界与依赖方向。
- [CHANGELOG.md](../CHANGELOG.md)：版本演进与发布记录。

其余资料按用途归档：

- `implemented/`：已实现能力的设计、验收、测试基线、交付报告及配套素材。
- `future/`：尚未完全落地的方案、路线图和后续计划。
- `reviews/`：架构审查及其他评审记录。

归档文档用于保留设计背景和历史决策；判断当前实现时，以根目录的 `ARCHITECTURE.md` 及代码为准。

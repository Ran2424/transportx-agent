# 取证分析

为数据问答任务选择「取证分析」模块。会话启动时开放 `analyze_workspace_table` 和 `complete_evidence_analysis`。每次任务会记录本轮读取或查询过的工作区来源。

- 对工作区内 UTF-8 CSV 可以选列、按精确文本等值过滤、分组、计数、求和或求平均。空字段按 NULL 处理。数值排序和数值最小/最大值使用 `numeric: true`。求和与数值边界使用精确十进制，结果附筛选后的记录数。
- 非空表的查询返回零行，且某个等值条件在整列中找不到时，`unmatchedFilters` 列出该条件及有限的源值样例。先核对实际值再重查。该回执可用于说明证据缺项，统计答案需要成功查询的证据。
- CSV 查询返回选定列、行、截断状态、来源摘要、查询计划和运行标识。当前工具一次查询一个 CSV。跨表分析使用已核对的关联输出或现有领域工具。
- 表格答案通过 `claims` 引用本轮表格证据。主查询的 `scope` 和 `sample` 必须使用同一证据 ID，且 `scope.expectedFilters` 中声明的过滤条件须与实际执行一致。用 `value` 指定结果列和行，用 `time` 引用按单一时间字段分组并统计全部行的完整查询。工作台取真实值生成结果。可选的分析说明单独供人工复核。源文件不存在或覆盖不足时，核对可用资料后提交具体缺项。
- 模块对选用本能力的数据问答执行交付校验。当 Agent 只给步骤或提交时缺少本轮证据，模块可触发一次只读补查，最多 6 次调用、180 秒。工作台单独显示交付已提交、待核对或尚未完成。

证据回执存入 Pi 会话历史，记录实际来源、文件摘要、工具调用、查询版本及提交的逐项事实。时间分布保留源文本和命中条数，时间口径是否合适仍需根据数据定义核对。样本量取筛选后总行数，独立于结果分页或排序截取。

提交时可用 `relatedToolCallIds` 引用本轮其他工具实际签发的回执。工具成功结果可用 `deliveryReference` 声明自动关联键。交付按键取本轮最后一张回执，显式引用优先。来源证据由本模块核对。

本机工程复现见 `node scripts/evidence-analysis-smoke.mjs --evidence <目录>`。

任务的 `SessionProfile.task.answerRequirements` 可列出需要解释的内容，例如口径、时间或适用范围。非空时，聚合工具不能直接交付，须通过 `complete_evidence_analysis` 提交包括这些说明的完整答案；未设置时保留原直交行为。引用受控快照时，查询证据同时保存其上游快照和定义引用。

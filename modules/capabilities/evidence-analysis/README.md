# 取证分析

为数据问答任务选择「取证分析」模块。会话启动时开放 `analyze_workspace_table` 和 `complete_evidence_analysis`。每次任务会记录本轮读取或查询过的工作区来源。

- 对工作区内 UTF-8 CSV 可以选列、按精确文本等值过滤、分组、计数或求和。空字段按 NULL 处理。数值排序和数值最小/最大值使用 `numeric: true`。求和与数值边界使用精确十进制，结果附筛选后的记录数。
- CSV 查询返回选定列、行、截断状态、来源摘要、查询计划和运行标识。当前工具一次查询一个 CSV。跨表分析使用已核对的关联输出或现有领域工具。
- 用实际读取或查询返回的本轮证据 ID 提交答案。源文件不存在或覆盖不足时，核对可用资料后提交具体缺项。
- 当 Agent 只给步骤或提交时缺少本轮证据，宿主允许一次补查。补查只用工作区只读证据工具及结果登记，最多 6 次调用、180 秒。若仍无法收尾，工作台显示本轮未完成或已核实的缺项。

证据回执存入 Pi 会话历史，记录实际来源、文件摘要、工具调用、查询版本和本轮选择的来源。回执用于复查。业务口径和结果数值仍按当前资料核验。

与「交通经验交换」同用时，回执可记录本轮检索结果和显式的采纳或跳过说明。匹配到候选与实际使用保持各自状态。

本机工程复现见 `node scripts/evidence-analysis-smoke.mjs --evidence <目录>`。

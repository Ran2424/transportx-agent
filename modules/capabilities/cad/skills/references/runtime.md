# 运行环境诊断

CAD 几何操作使用 Host 的受控 Python 与模块脚本，Viewer 使用浏览器运行时。不要在任务中安装另一套服务或修改系统 Python 来绕过能力检查。

先查询能力状态和实际错误；检查 ezdxf、pyproj、shapely、matplotlib 是否由当前运行时提供。开发环境允许显式覆盖解释器，不能将开发者个人路径写入模块。

字体从运行时实际可用字体中解析，不按操作系统猜测字体已安装。浏览器显示和 Python 导出分别核对；一侧成功不能证明另一侧可用。缺 CJK 字体时说明限制，不把方框当成成功中文标注。

macOS 与 Windows 的解释器入口、原生依赖与发布规则由平台 profile 维护；共同使用相同的 CAD 工具协议和图纸语义。平台验收状态查项目开发记录，不根据运行系统推断已经验收。

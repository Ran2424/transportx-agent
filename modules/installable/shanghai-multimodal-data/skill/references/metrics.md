# 指标定义

## 业务指标

| 指标 | 字段 | 粒度 | 单位 |
|---|---|---|---|
| 地铁进站量 | `metro_flow_hour.entry_flow` | 线路—站点—小时 | 人次 |
| 地铁出站量 | `metro_flow_hour.exit_flow` | 线路—站点—小时 | 人次 |
| 公交客流量 | `bus_flow_hour.passenger_flow` | 线路—小时 | 人次 |
| 出租车上车量 | `grid_flow_hour.taxi_pickups` | 网格—小时 | 次 |
| 出租车下车完单量 | `grid_flow_hour.taxi_dropoffs` | 网格—小时 | 次 |
| 网约车下单量 | `grid_flow_hour.ridehail_orders` | 网格—小时 | 单 |
| 网约车下车完单量 | `grid_flow_hour.ridehail_dropoffs` | 网格—小时 | 单 |
| 共享单车锁车量 | `grid_flow_hour.bike_locks` | 网格—小时 | 次 |
| 实体距离 | 三张距离表的 `distance_m` | 实体对 | 米 |

## 时间口径

- 早高峰：7、8、9 时。
- 晚高峰：17、18、19 时。
- 夜间：0—5 时。
- “全天”指数据库中 `2026-08-24` 对应指标的有效观测范围，不将缺失小时补零。

## 缺失与聚合

- `NULL` 表示没有对应指标观测，不能自动解释为零。
- 数值 `0` 表示存在观测且观测值为零。
- 共享单车同一小时的 0 分和 30 分观测已相加。
- 地铁物理站总量需要汇总该 `station_id` 的全部线路记录。
- 地铁进站量与出站量是两个流量指标，相加后仍不是去重乘客数。
- 不同交通方式的单位和业务含义不同；并列比较时分别保留原指标名称与单位。
- 比值、占比和差值明确分子、分母与参与计算的有效观测范围。

# 重大活动交通保障知识资料库

更新时间：2026-07-26

本目录汇集重大活动交通保障方案、应急预案和辅助决策智能体可参考的项目资料、法规规范、行业制度、国家标准全文及元数据、上海案例和方法指南。

> 强制要求：新增、迁移或重新处理任何文档前，必须先阅读并遵循 [知识库入库规范](SPEC.md)。未通过规范验收的文档不得进入 Agent 默认检索范围。

## Agent 结构化入口

Agent 默认使用下列规范化目录，不直接检索后文所列的历史平铺目录：

- [_catalog/documents.jsonl](_catalog/documents.jsonl)：全局文档目录与验收状态；
- [_catalog/INGESTION_REPORT.md](_catalog/INGESTION_REPORT.md)：本批入库统计、解析方式与限制；
- `01_法律法规与制度`至`06_项目资料与数据定义`：每份文档一个目录，包含原件、页级记录、层级树、知识卡和验收记录；
- 单文档优先读取`data/tree.json`或`data/index.md`导航，再读取`data/knowledge.jsonl`和`data/nodes.jsonl`核对原文及出处。

后文的`00_项目资料`至`06_方法指南`为保留的原始资料区，用于追溯和重建，不得删除。

## 使用顺序

生成保障方案或预案时，建议按以下优先级引用：

1. 现行法律、行政法规和国家总体预案；
2. 上海市现行规章、规范性文件和专项预案；
3. 交通运输行业管理规定及运营规范；
4. 国家标准的结构和技术要求；
5. 同类活动案例与国内外方法指南。

案例和国外指南只能用于补充组织方法、措施库和检查清单，不应替代中国及上海现行法规。

## 用于方案／预案生成时的边界

- 可以支撑：法规依据清单、活动画像、交通需求与风险情景、组织架构、分区分时交通组织、公共交通与接驳、停车与上下客、客流控制、应急响应、信息发布、演练和复盘等章节的初稿与检查。
- 仍需补充：活动具体日期、场馆及周边路网、票务与客流预测、施工占道、实时交通、气象、警力与运力资源、部门职责确认、管制审批结果。
- 必须人工审核：涉及封路、停运、限流、安保等级、应急响应启动、警力部署和对外发布的措施。
- `上海轨交公交及非重大活动突发大客流交通应急预案`中的“非重大活动”预案可参考其机制和措施，但不能直接替代重大活动专项保障方案。

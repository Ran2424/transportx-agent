# 重大活动交通态势数据梳理报告

更新时间：2026-07-20  
资产版本：2.0.0

## 1. 报告边界

本报告只陈述当前文件和SQLite资产中可以验证的内容。题目场景涉及上海体育场周边重大活动交通，但数据并非所有领域都覆盖全上海或完整活动周期。

`common.dim_event` 中的2025-08-20、21、23、24四条活动记录来自用户提供的日期级信息。数据中没有可靠的开演、结束、进场或散场时刻，不据交通峰值反推。

## 2. 原始治理库

`data/traffic_governance.sqlite` 当前登记32个源数据集、2,534,244条源记录：

| 目录 | 数据集数 | 记录数 | 定位 |
|---|---:|---:|---|
| `data/amap_metro` | 6 | 2,152 | 2026-07-19高德轨交方向线路、站点、站序、几何和采集报告 |
| `data/bus` | 6 | 5,963 | 2026-07-10高德公交方向线路、站点、站序、几何和采集报告 |
| `data/metro` | 6 | 1,805 | 遗留20条统一线路、413个旧物理站点及旧坐标匹配结果 |
| `data/poi` | 2 | 2 | 用户提供的上海体育场POI记录和几何 |
| `data/徐汇区各业态数据` | 12 | 2,524,322 | 路网、客流、网约车、支付订单、气象和官方公交基础数据 |

各文件字段和样例以各目录自动生成的 `data.md` 为准。高德GeoJSON未声明CRS；依据CSV采集字段，公交和新轨交高德点线按GCJ-02接纳，不能直接当WGS84使用。

## 3. 标准资产

标准资产由 `scripts/build_agent_data_assets.py` 生成，分为 `catalog`、`common`、`road`、`metro`、`bus`、`ridehail` 六个SQLite数据库。

### 3.1 统一坐标规则

- 公交和轨交标准字段 `longitude`、`latitude`、`geometry_json` 统一为WGS84经纬度，`normalized_crs='EPSG:4326'`。
- 高德原始GCJ-02坐标保留在治理库以及 `source_x/source_y/source_geometry_json` 中。
- 官方公交站的EPSG:32651源坐标保留，并通过 `pyproj` 转为EPSG:4326。
- 场馆POI、天气和部分订单源没有可靠CRS时继续标记 `UNKNOWN`。数值看似经纬度不等于已知WGS84。

因此，旧报告中“上海体育场POI为GCJ-02、可以直接据此做300米/500米圈层”的说法不成立。确认POI源CRS前，只能进行带限制说明的局部展示，不能与WGS84交通网络做精确距离计算。

### 3.2 轨交

| 对象 | 数量 | 说明 |
|---|---:|---|
| 统一线路 | 20 | 保留既有稳定 `line_id` |
| 高德方向/支线路径 | 46 | 5、10、11号线各含4个方向/支线路径，其余线路各2个 |
| 统一物理站点 | 420 | 既有ID保持稳定，新增站使用414–420 |
| 高德站点ID映射 | 420 | 407个按源ID、6个按唯一精确站名、7个作为高德新增站接纳 |
| 高德方向站序 | 1,200 | 保留路线级站点坐标和序号 |
| 统一线站关系 | 532 | 保留线路上下文WGS84站点和点线距离 |
| 轨交小时客流 | 7,975 | 仅覆盖10个所选站点、7条线路，不是全市轨交客流 |

方向站序点和统一线站上下文点到对应高德线路几何的最大距离均为0米。换乘站的不同线路平台可能相距较远，因此路线图使用关系表坐标，不强制所有线路使用一个物理站中心点。

遗留站“严御路”没有可靠坐标，新高德11号线中也没有该站。资产保留其统一ID和客流连接能力，但坐标为空，不构造虚假位置。

### 3.3 公交

| 对象 | 数量 | 说明 |
|---|---:|---|
| 官方线路 | 77 | 客流连接使用的统一线路维度 |
| 高德方向线路 | 151 | WGS84标准几何，保留GCJ-02源几何 |
| 来源站点 | 1,272 | 194个官方站点、1,078个高德站点，不做未经验证的一一合并 |
| 高德方向站序 | 3,428 | 保留每条方向线路返回的站点坐标 |
| 公交半小时客流 | 55,339 | 75条线路映射成功，不是全市公交客流 |

同一高德 `stop_id` 在不同线路中可能返回不同坐标。资产不再用主站点单点替代所有停靠位置；方向线路制图使用 `bus.bridge_bus_line_stop.longitude/latitude`。全部高德方向站序点到对应线路几何的最大距离为0米。

### 3.4 其他领域

- 路网：89个发布段、21,775条状态事件。源数据没有路段几何，不能将路段精确分配到场馆圈层。
- 网约车：默认事实1,275,581条；其中仍有1,684条记录源CRS未知并明确标记。
- 场馆订单：默认事实1,150,668条；29条无效坐标记录已排除。
- 气象：8个徐汇网格、11,384条有效观测。`rainfall_1h_mm` 是滚动一小时累计量，不能对10分钟记录求和。

## 4. 实体与客流连接

- 轨交客流只通过统一 `line_id`、`station_id` 连接；高德方向线路ID和站点ID保存在映射表中。
- 公交客流通过官方 `line_key` 连接；高德方向线路用于静态供给和空间制图。
- 公交交易数、轨交人次和网约车订单量纲不同，只能并列比较趋势，不能相加为“总客流”。
- 订单号不进入资产包，仅保存不可逆SHA-256哈希。

## 5. 构建质量结果

当前错误级规则全部通过：

- 32个源数据集全部登记。
- 公交和轨交客流维度映射无遗漏。
- 420个高德轨交站点ID全部映射。
- 公交、轨交路线级点线距离均不超过25米。
- 存在空间值的公交、轨交标准对象全部为EPSG:4326。
- 默认事实表不暴露源业务ID，订单ID已脱敏。

仍保留并明确报告的警告：活动具体时刻缺失、严御路坐标缺失、部分网约车CRS未知、少量场馆订单坐标无效。
